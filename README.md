# ✦ Embracing Art 2.0

A visual web project exploring the intersection of **photography**, **cognitive memory**, and **mental wellness**.

## About

This single-page site examines how photography as an art form enhances memory retention and supports mental health — backed by academic research and brought to life through a curated personal photo gallery.

## Sections

| # | Section | Description |
|---|---------|-------------|
| 01 | Abstract | Project overview and objectives |
| 02 | What is Art? | Definition and role of visual art |
| 03 | Photography | Photography as a creative medium |
| 04 | Impact on Memory | Cognitive and emotional memory effects |
| 05 | Photography & Mental Health | 7 key mental health benefits |
| 06 | Gallery | Personal photo gallery with lightbox |
| 07 | References | Academic sources |

## Tech Stack

- **HTML / CSS / JavaScript** — vanilla, no frameworks
- **[Swiper.js](https://swiperjs.com/)** — gallery carousel
- **[GLightbox](https://biati-digital.github.io/glightbox/)** — photo lightbox

## Running Locally

Open `index.html` directly in a browser — no build step required.
